# Splat's Optimizer

windows debloat / tweak tool with a gui.

**[download the latest version here](https://github.com/wesplat2/splats-optimizer/releases/latest)** - unzip it anywhere and run `Splats Optimizer.exe` (asks for admin). keep the exe and the `assets` folder together.

- `assets/` - the app itself, plus its fonts and app icons
- `launcher-src/` - source for the exe launcher

## updates

hit **check for updates** on the start page. it checks the latest release here and offers to update if there's a newer one.

google sans is under the SIL open font license (`assets/fonts/OFL.txt`).
